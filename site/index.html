About the data

Sources and cleaning
  • Names tagged FOCUS are the specification's. Names tagged lab, and columns with a dotted underline, were made by this lab: hover over one to see why.
  • cau_sample is the FinOps Foundation's FOCUS-Sample-Data: anonymised FOCUS 1.0 data from AWS, Microsoft, Oracle and a little Google. Costs are anonymised: read the method, not the money.
  • It is not FOCUS 1.5 data. So that 1.5 queries can run on it, the lab added every 1.5 column it lacks, empty. It derived ServiceProviderName and HostProviderName from ProviderName, PublisherName and InvoiceIssuerName using the spec's migration guidance. The 1.0 columns that later versions removed are kept.
  • The sample writes missing values as the text NULL. These were loaded as nulls.
  • cau_examples and the other tables come from the specification's worked-example CSVs. Each file is a separate scenario, so filter by x_ExampleFile before you add anything up. Some files used the text null or currency text such as $10,000.00 in Decimal columns. These were cleaned on load.
  • Decimal columns are 64-bit floating point, one of the precisions the spec allows. Sums of charges and credits can leave tiny remainders instead of exactly zero.
